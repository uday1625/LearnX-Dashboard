# EduQuest 🚀
### A Gamified CS Student Guidance & Learning Dashboard

EduQuest is a comprehensive, premium-designed learning platform that guides computer science students through diverse domains (Web Dev, DSA, Data Science, Cybersecurity) using interactive roadmaps, gamified milestones, hands-on sandboxes, and advanced learning tools.

---

## 🌟 Key Features

### 🗺️ Interactive Learning Roadmaps
* **Domain Roadmaps**: Tailored curriculum tracks for **Web Development**, **Data Structures & Algorithms (DSA)**, **Data Science**, and **Cybersecurity**.
* **Inline Video Lessons**: Curated YouTube resources that play directly inside the dashboard using an embedded custom player.
* **Progress Tracking**: Checkboxes for each milestone dynamically update progress bars and unlock subsequent levels.

### 🤖 AI Study Counselor
* **Interactive Guidance**: A chatbot counselor to help students choose their domains, construct study plans, and answer conceptual questions.

### 📊 Gamified Analytics Dashboard
* **GitHub-Style Heatmap**: An interactive XP consistency calendar mapping daily learning activity.
* **Radar Strength Chart**: A dynamic SVG radar chart displaying user proficiency across Web Dev, DSA, Data Science, and Cybersecurity.
* **Badges & Levels**: Dynamic level progression based on XP with unlockable achievement badges.

### 🎯 Daily Quests & Shop
* **Dynamic Objectives**: Daily tasks (e.g., "Complete a mock interview", "Fix a code vulnerability") that reward XP upon completion.
* **XP Store**: Redeem accumulated XP to purchase items like **Streak Freezes** to maintain consistency.

### 💻 Multi-Mode Coding Sandboxes
* **Frontend Sandbox**: A live editor for Web Dev containing side-by-side **HTML/CSS/JS** input panels and a real-time rendered output frame.
* **Console Sandbox**: A JavaScript code runner with evaluated logs, perfect for solving DSA, Data Science, and Cybersecurity challenges.

### 🃏 AI Flashcards & Match Game
* **Flippable Cards**: Study vocabulary and core principles with 3D flippable card decks.
* **Term-Matching Game**: A timed, scattered card game matching terms with definitions.

### 👔 Mock Interviewer
* **Interactive Screening**: Practice for internships and full-time roles with an interactive, conversational mock interviewer.
* **Feedback Report**: Receive a comprehensive evaluation with performance scores, strengths, weaknesses, and model answers.

### 🛡️ Bug Bounty Simulator (Killer Feature)
* **Vulnerability Auditor**: Inspect vulnerable code blocks (SQL Injection, division by zero, infinite recursion, insecure MD5 hashing).
* **Interactive Audit**: Click directly on the faulty line of code, describe the fix, and claim XP bounties upon validation.

---

## 🛠️ Technology Stack

* **Frontend**: React.js, Vite, Vanilla CSS (Premium Glassmorphism & Custom SVG Charts)
* **Backend**: Node.js, Express.js, REST APIs
* **Database**: Local JSON Database (`db.json`) for student profiles, daily quests, and bug bounty challenges.
